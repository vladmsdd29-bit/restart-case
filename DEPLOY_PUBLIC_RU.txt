RESTART CASE — ПУБЛИЧНЫЙ ЗАПУСК

Что исправлено:
- Метка редкости на карточках теперь компактная (точный CSS-селектор .caseArt span.caseRarity).
- Данные разделены по браузерным сессиям: посетители не используют один общий баланс/инвентарь.
- Данные сохраняются в STORE_DIR; конфигурация Render использует постоянный диск.

Публикация через Render + GitHub:
1. Создайте репозиторий GitHub и загрузите в него все файлы этой папки (включая render.yaml). Не загружайте restart-case-data.json с личными данными.
2. Войдите в Render: https://dashboard.render.com/
3. Выберите New -> Blueprint, подключите репозиторий с проектом и примените Blueprint из render.yaml.
4. Render создаст Node.js web service и постоянный диск 1 GB. План Starter платный; бесплатный web service не поддерживает persistent disk и теряет локальные файлы при перезапусках.
5. После успешного deploy откройте выданный адрес *.onrender.com.

Важно:
- Это демонстрационный сайт с виртуальными монетами. Нет Steam-авторизации, платежей, реальной торговли или вывода средств.
- Баланс каждого посетителя привязан к cookie браузера. Очистка cookie сбрасывает его профиль.
- Для настоящих аккаунтов, защиты от накрутки и масштабирования понадобится отдельная БД и авторизация.
